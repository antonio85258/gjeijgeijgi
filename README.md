# my-first-next-app

Готовый проект для практической работы №1.2 «Введение в Next.js».

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Реализовано

- App Router
- главная страница `/`
- страница `/about`
- Server Component с async/await
- Client Component `Counter` с `useState`
- динамический маршрут `/blog/[slug]`
- `generateStaticParams`
- страницы `/blog/nextjs-vvedenie` и `/blog/react-osnovy`
- API-маршрут `/api/hello`

## Проверка сборки

```bash
npm run build
npm start
```
